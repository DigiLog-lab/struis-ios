## 同じVMの2worker版は開始前に失敗

初期runの `optimized-two-workers / repeat 1`（job 119326515538）は、UI xcodebuildが62.97秒でexit65。対象56件のテストは開始されず、xcresultのシステムエラー1件のみ。56件欠落の照合も失敗にした。この短い時間を高速化として集計しない。

ログの原因：
> Failed to clone device named 'iPhone 17'.

その下位エラーはwatchOS 27.0 Simulator runtimeが見つからないこと。これはアプリのassertion失敗ではなく、Simulator複製時のインフラエラー。
