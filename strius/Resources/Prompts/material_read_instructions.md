# Struis 範囲の読み取り

生徒が「単元を作る」で撮った写真(テストの範囲表、教科書の目次やページ、大学のシラバス、講義のスライド、小テスト)から、単元を作るのに要る範囲を読み取ってください。読み取った値は確認の画面にそのまま出し、生徒が直せます。

## 依頼の中身

- `grade`: 生徒の学年(「中3」「高2」など)。大学生・それ以外の時は「大学生・それ以外」。
- `units`: 生徒の学年(と前後の学年)の数学の単元の名前の一覧。
- `today`: 今日の日付(「2026-11-11」)。
- 添付の画像: 撮った写真(1〜8枚)。

## 決めること

写真に書いてある値だけを返してください。書いていない値は空(数は 0、一覧は空)にし、推測で埋めないでください。

- `readable`: 写真から範囲を読み取れたか。白紙・ぶれ・範囲と関係ない写真なら false にし、ほかは空にします。
- `kind`: 写真の種類。範囲表 `range_sheet`、教科書の目次やページ `textbook`、シラバス `syllabus`、講義のスライド `slides`、小テスト `quiz`、それ以外 `other`。複数の種類があれば、範囲を一番よく表すもの。
- `subject`: 科目(「数学Ⅱ」「線形代数Ⅱ」)。範囲表に複数の科目がある時は、数学の科目を選んでください(Struis は今は数学だけです)。数学が無ければ、最初の科目。
- `unit`: 中学・高校の時、範囲にあたる単元の名前。`units` の中に当てはまるものがあれば、その名前をそのまま返します。当てはまらなければ、写真に書いてある章の名前。大学生なら空。
- `course`: 大学の授業の名前(シラバス・スライドにあるもの)。中学・高校なら空。
- `pages`: 教科書のページの範囲(「p.98〜p.131」)。
- `workbook_pages`: 問題集やワークのページの範囲と名前(「ニューアクションβ p.54〜p.70」)。
- `test_date`: 選んだ科目のテスト・試験の日付(「2026-11-27」)。年が書いていなければ、`today` より後で一番近い年にします。
- `lectures`: シラバスの授業計画の回(番号と題)。シラバスで無ければ、写真に出ている回だけ。
- `latest_lecture`: スライドや小テストに書かれた回の番号のうち、一番大きいもの(授業がそこまで進んだしるし)。シラバスだけなら 0。
- `words`: 範囲に出てくる大事な言葉を5つまで(「微分係数」「導関数」など)。
