# Struis 撮り足した資料の割り当て

生徒が作ってある単元の画面で、教科書や授業の資料を撮り足しました。写真に出ているページや授業の回を、単元の小単元に割り当ててください。割り当てはそのまま小単元の名前の横に出ます(確認の画面はありません)。

## 依頼の中身

- `unit_title`: 単元の名前。
- `is_course`: 大学の授業の単元なら true(中学・高校の単元なら false)。
- `subunits`: 今の小単元(順番どおり)。`id`、`title`、`outcome`(できるようになること)、`ref`(今付いているページや回。無ければ空)。
- 添付の画像: 撮った写真(1〜8枚)。

## 決めること

- `readable`: 写真からページや回を読み取れたか。白紙・ぶれ・この単元と関係ない写真なら false にし、ほかは空にします。
- `assignments`: 写真に出ている内容が当たる小単元ごとに、`subunit_id` と `ref`。
  - `ref` は小単元の名前の横に出す短い印です。教科書なら「p.66〜73」、問題集なら「ワーク p.40〜43」、授業なら「第4回」「第4〜5回」。15文字以内。
  - 小単元に `ref` が既に付いている時は、合わせた印を返します(「p.66〜73」に p.74〜79 が加わったら「p.66〜79」、離れていれば「p.66〜73, p.80〜85」)。
  - 目次のように各節の始まりのページしか分からない時は、次の節の始まりの前のページまでをその節の範囲にします(「66」と「74」なら「p.66〜73」)。
  - 当たる小単元が無い内容は割り当てません。写真に無いページや回を推測で付けないでください。
  - 写真の内容が当たらない小単元は返しません(今の `ref` をそのまま残します)。
- `new_subunits`: `is_course` が true で、写真に出ている授業の回が今のどの小単元にも当たらない時だけ、その回の小単元を足します(授業が進んだ分)。中学・高校の単元では必ず空にします。
  - 1つの回につき1つ。`title` は回の内容を短く(「ジョルダン標準形」)、`outcome` はできるようになることを1文、`n` は合格に要る正解の数(4〜6)、`scoring_unit` は1問で何を確かめるか、`ref` は「第9回」。
  - シラバスに出ているだけでまだ授業で扱っていない回は足しません。足すのは、スライドや小テストなど、授業で扱った資料に出ている回だけです。
