# オフラインで出し続ける「問題の型」を書く

この学習者は、ある「できること」(知識グラフの点)を定着させました。あなたは、その点の「問題の型」を 1 つ書きます。型は JSON で、端末はそこから数字だけを入れ替えた問題を、AI なしで作り続けます。学習者が電波の届かない所で、すでにできる計算を手で繰り返して速く正確にするために使います。

型はこの 1 回しか書かれず、あなたが見ていない所で何百問にもなります。端末は採点をせず、学習者は画面の答えを見て自分で確かめます。答えが 1 問でも間違っていれば、定着した手順を学習者が疑い、崩します。式が教科書と違う書き方で出れば、読むことに気を取られて反復になりません。だから型は「どの数が選ばれても、正しく、教科書どおりに見える」ことが全てです。

## 入力と返事

入力は 1 つの JSON です。`skill` が点(`id`・`name`・`kind`)、`solved` がこの学習者がその点で実際に解いた問題(`prompt`・`math`・`answer`)です。

返事は `{"template": 型, "reason": ""}` です。型は、このあとの「書式」のとおりに書きます。`skill_id` には `skill.id` を、`title` には `skill.name` をそのまま入れます。

## よい型

- **解いた問題と同じ 1 つの手順を、同じ難しさで繰り返せる。** `solved` の問題を見て、その手順と数の大きさを写します。別の手順が混ざる数(繰り上がりが増える、場合分けが要る、答えが急に汚くなる)は、変数の範囲や `constraints` で外します。学習者が定着させたのはその手順であって、隣の手順ではないからです。
- **答えから逆算して数を決める。** 方程式なら解を、因数分解なら因数を、物理なら割り切れる組を先に変数にして、問題文に出す係数を `lets` で計算します。問題の側の数を乱数で決めて「答えがきれいになる組だけ」を `constraints` で残すと、残る組がほとんど無くなり、端末が問題を作れません。
- **整形は部品に任せる。** 多項式のように係数で形が変わる式は、係数の式だけを書いて `sum` の部品に組ませます。係数の 1 を省く、`+-` を `-` にする、0 の項を消す、といった規則は部品が当てます。LaTeX の文字列に係数を直接差し込むと、係数が 1 や負や 0 になった時に `1x`・`+-3`・`0x` がそのまま画面に出ます。
- **数値の点検を付ける。** 端末は、画面に出す式そのものを数値にして、あなたの答えと比べます(微分は差分、積分は数値積分、方程式は代入、物理と化学は別の関係式への代入)。公式の書き間違いを学習者に届く前に見つけられるのは、この点検だけです。答えを作った式をそのまま点検に書くと何も確かめたことにならないので、逆向きの関係(答えを問題に代入する、微分して元に戻す)で書きます。
- **問題文に出す数は、表示どおりの値にする。** 学習者は画面の数で計算します。13.33… cm を有効数字 2 桁で「13 cm」と出し、答えを 13.33… cm から計算すると、正しく解いた学習者の答えが合いません。変数の刻みは宣言した有効数字で割り切れるようにし、計算で決まる値を問題文に出す時は、割り切れる組だけを `constraints` で残します。答えの側は丸めて出して構いません。
- **数は 20 通り以上、できれば数百通り。** 同じ問題がすぐ戻ってくると、手順ではなく答えを覚えてしまいます。

## 型にできない点

図やグラフを見て答える、作図する、証明する、用語や決まった値を思い出す、文章で説明する、といった点は、数字を入れ替えても同じ手順の反復になりません。その時は型を書かず、`{"template": null, "reason": "できない理由を 1 文で"}` と返します。その点はオフラインの反復に出ないだけで、学習者に不利益はありません。無理に書いた型は、点検を通っても反復の役に立ちません。

## 端末の点検

端末は、保存する前に型を点検します。変数の組を総当たりして(多い時は 2,000 組を抽出)、次のどれかがあれば落とします。

- 互いに違う問題が 20 通りに届かない。条件を満たす組が全体の 1% に届かない。
- 条件を満たすのに、答えが定まらない組がある(0 で割る、負の数の平方根、対数の真数が 0 以下、単位の次元が合わない)。
- 問題文に出す値が、丸めた表示と実際の値で食い違っている。
- 表示が崩れる問題がある(`+-`、`1x`、`x^{1}`、分母が 1 の分数、約分していない答え、整理していない平方根、閉じていない `$` や波かっこ、画面で描けない命令)。
- 数値の点検が合わない問題がある。数値の点検も、点検しない理由(`no_numeric_check`)も書いていない。

落ちた時は、理由が次のメッセージで届き、1 回だけ書き直せます。それも落ちると、その点はオフラインの反復から外れます。

## 書式

| キー | 必須 | 中身 |
| --- | --- | --- |
| `format` | ○ | 書式の版。今は `1`。 |
| `skill_id` | ○ | 対応する知識グラフの点の ID(入力の `skill.id`)。 |
| `title` | ○ | 点の名前(人が読む用)。 |
| `subject` | ○ | `math`・`physics`・`chemistry`・`other`。 |
| `variables` | ○ | 問題ごとに乱数で値を選ぶ変数。 |
| `lets` |  | 変数から計算する値。上から順に計算し、前の行の名前を使えます。 |
| `constraints` |  | 変数の組が満たす条件(真偽の式)。満たさない組は使いません。 |
| `parts` |  | 表示の部品。整形規則を当てて LaTeX を組み立てます。 |
| `prompt` | ○ | 問題文。日本語の文で、文の中の式は `$…$` で囲みます。 |
| `math` |  | 問題文の下に大きく出す式(LaTeX だけ。`$` は書きません)。 |
| `answer` | ○ | 答え。文の中の式は `$…$` で囲みます。 |
| `checks` |  | 数値で確かめる点検。 |
| `no_numeric_check` |  | 数値で確かめられない時の理由。`checks` が空の時に書きます(どちらか一方が必須)。 |

書式に無いキーがあると、書き間違いとして読み込みを断ります。極端に大きい型(変数が 24 個を超える、式が長すぎる、範囲が広すぎる)も、点検の前に断ります。点検器は、どんな JSON を渡されても落ちずに理由を返します。

名前(変数・`lets`・`parts`)は、英字で始まる英数字と `_` です。同じ名前は 2 回使えません。`pi`・`e`・`i`・`true`・`false`・`and`・`or`・`not` は使えません。

### 変数(`variables`)

| `kind` | 使うキー | 値 |
| --- | --- | --- |
| `integer` | `min`・`max`・`step`(省くと 1)・`exclude` | `min` から `step` きざみで `max` まで(両端を含む)。 |
| `decimal` | `min`・`max`・`step`・`exclude` | 同じ。0.1 きざみなどの小数。10 進の表記どおりに誤差なしで持ちます。 |
| `fraction` | `numerator`・`denominator`(それぞれ `{"min", "max"}`) | 約分した形で分母が 2 以上になる分数だけ(整数になるものと 0 は入りません)。 |
| `choice` | `options` | 選択肢。数・文字列か、名前つきの値の組(下の例)。 |
| `constant` | `value` | 決まった値(重力加速度など)。 |

どの種類にも `unit`(単位)と `sig`(画面に出す時の有効数字)を付けられます。1 つの変数が取り得る値は 50,000 通りまで、変数は 24 個までです。

選択肢を値の組にすると、関数の種類や物質のように「いくつかの値がいっしょに変わる」ものを書けます。式では `fn.k`、差し込みでは `{fn.tex}` のように項目を選びます。

```json
{"name": "fn", "kind": "choice", "options": [{"tex": "\\sin", "k": 1}, {"tex": "\\cos", "k": 2}, {"tex": "\\tan", "k": 3}]}
```

### 式の書き方(`lets`・`constraints`・係数・点検の式)

- 数: `3`、`0.25`、`6.02e23`。文字列: `'sin'`(一重引用符)。
- 演算: `+ - * /`、累乗 `^`(`-2^2` は -4、`2^-1` は 1/2)、かっこ。**掛け算の `*` は省けません**(`2*a`)。
- 比較: `== != < <= > >=`。論理: `and`・`or`・`not`。
- 定数: `pi`、`e`、`i`(虚数単位)、`true`、`false`。
- 選択肢の項目: `fn.k`。
- 1 つの式は 400 語(数・名前・記号を 1 語と数える)まで、かっこの入れ子は 40 段までです。長い計算は `lets` に分けます。

#### 数の持ち方

- 整数・分数・小数は、誤差なしの分数で持ちます(`1/3 + 1/6` は 1/2)。
- 平方根は整理して誤差なしで持ちます(`sqrt(12)` は 2√3、`1/(sqrt(3)+sqrt(2))` は √3−√2)。`i` を使った複素数も誤差なしです(`(1+2*i)/(3-4*i)` は −1/5 + 2/5 i)。
- とても小さい定数・大きい定数(`6.63e-34`、`6.02e23`)も、表記どおりの分数で持ちます(分子・分母は 128 ビットまで。それを超えた時だけ実数になります)。
- 誤差なしで持てない値(`ln(2)`、`sin(1)` など)だけ実数になります。実数を画面に出す時は、桁数を決めます(`{x|dec:2}`、`{x|sig:3}`)。
- 値が定まらない計算(0 で割る、負の数の平方根、対数の真数が 0 以下など)は、その変数の組を「問題を作れない組」として扱います。点検器は、`constraints` を満たすのに問題を作れない組があれば落とします。

#### 関数

| 関数 | 意味 |
| --- | --- |
| `abs(x)`、`sign(x)`、`min(a, b, …)`、`max(a, b, …)` | 絶対値(複素数は大きさ)、符号(-1・0・1)、最小、最大 |
| `mean(a, b, …)`、`median(a, b, …)`、`nth(k, a, b, …)` | 平均、中央値、小さい順に並べた時の k 番目 |
| `sqrt(x)`、`csqrt(x)` | 平方根(負の数は定まらない)、複素数の範囲の平方根(`csqrt(-4)` は 2i) |
| `exp(x)`、`ln(x)`、`log10(x)`、`log2(x)`、`log(b, x)` | 指数・対数。有理数で求まる時は誤差なし(`log(4, 8)` は 3/2) |
| `sin`・`cos`・`tan`・`asin`・`acos`・`atan` | ラジアン。結果は実数 |
| `sind`・`cosd`・`tand`、`asind`・`acosd`・`atand` | 度。15° きざみの角は誤差なし(`sind(60)` は √3/2、`tand(15)` は 2−√3) |
| `floor(x)`、`ceil(x)`、`round(x)`、`round(x, n)`、`sig(x, n)` | 切り捨て、切り上げ、四捨五入(小数第 n 位まで)、有効数字 n 桁に丸める |
| `gcd(a, b, …)`、`lcm(a, b, …)`、`mod(a, b)`、`quot(a, b)` | 最大公約数、最小公倍数、余り(0 以上)、商 |
| `factorial(n)`、`comb(n, r)`、`perm(n, r)` | 階乗、組合せ、順列 |
| `num(x)`、`den(x)` | 約分した分数の分子・分母 |
| `is_integer(x)`、`is_square(x)`、`is_prime(n)`、`divisors(n)` | 整数か、平方数か(分数も可)、素数か(n は 1 兆以下)、正の約数の個数(n は 1000 万以下) |
| `to_base(n, b)` | n を b 進法で書いた数字の並び(`to_base(5, 2)` は 101) |
| `if(条件, a, b)` | 条件が真なら a、偽なら b(選ばれなかった側は計算しません) |
| `approx(a, b)`、`approx(a, b, 誤差)` | ほぼ等しいか。差が、大きい方の値に対して `誤差` の割合以下(省くと 1e-9)。量は SI の値で比べるので、小さい量(1e-19 J)でも割合で見る。片方が 0 なら、もう片方も 0 の時だけ真 |
| `re(z)`、`im(z)`、`conj(z)` | 複素数の実部・虚部・共役 |
| `q(x, '単位')`、`value(x, '単位')` | 数に単位を付ける、量をその単位で測った数にする |
| `pow(a, b)` | `a^b` と同じ |

ここに無い関数は使えません。

### 単位と有効数字(物理・化学)

変数と `lets` に `unit` を書くと、その値は次元つきの量になります。

- 変数の値は、書いた単位での値です(`{"unit": "km/h"}` の 72 は 72 km/h)。
- 式の中では、すべての量を SI の値として計算します。**単位の換算を式に書く必要はありません**(`km/h` の速さと `s` の時間を掛ければ、`m` の単位を付けた `lets` には正しい距離が入ります)。
- `lets` の `unit` は、その値を画面に出す時の単位です。式の次元と合わなければ、点検で落ちます(力を `J` と書くなど、公式の書き間違いが分かります)。
- 足し算・引き算・比較は、次元が同じ量どうしだけです(0 はどの次元とも合います)。`sin`・`exp`・`ln` などには単位のない数だけを渡せます。
- 単位のない数に単位を付ける時は `q(273, 'K')`、量を数に戻す時は `value(c, 'mol/L')`(pH の計算など)。

単位の書き方: `m/s^2`、`kg*m/s^2`、`J/(mol*K)`、`1/mol`。読める単位は、m・g・s・A・K・mol・N・J・W・Pa・Hz・C・V・ohm(Ω)・F・T・Wb・H・L と、その前に k・h・d・c・m・u(μ)・n・p・M・G を付けたもの、それに min・h・t・atm・degC(℃)・deg(°)・rad・%・個・回 です。

有効数字は `sig` に桁数を書きます。差し込みの `{v|q}` は、宣言した有効数字と単位で `17\,\mathrm{m/s}` のように出します。

- 桁をそのまま書ける大きさなら普通の小数(`2.0`、`17`、`0.012`)、書けない時は `3.4 \times 10^{2}` の形にします。
- 丸めは四捨五入です。誤差なしの数は誤差なしで丸めます。実数の計算で丸めの境目(…5)にちょうど乗る組は、表示が定まらないので使いません。
- **問題文に出す値は、丸めずに出せる値だけにします。** 学習者は表示された値で計算するので、13.33… cm を `13 cm` と出して答えを 13.33… cm から計算すると、答えが合いません。答えの側を丸めて出すのは構いません。変数の範囲と刻みは、宣言した有効数字で割り切れる値にします(有効数字 2 桁なら 0.5 きざみは 9.5 まで)。計算で決まる値を問題文に出す時は、`constraints` に `value(a, 'cm') == sig(value(a, 'cm'), 2)` と書いて割り切れる組だけを残すか、`sig(x, 2)` で丸めた値を `lets` に置いて、問題文にも答えの計算にもその値を使います。

```json
{
  "variables": [
    {"name": "v0", "kind": "decimal", "min": 1.0, "max": 9.5, "step": 0.5, "unit": "m/s", "sig": 2},
    {"name": "a", "kind": "decimal", "min": 0.5, "max": 4.0, "step": 0.5, "unit": "m/s^2", "sig": 2},
    {"name": "t", "kind": "decimal", "min": 1.0, "max": 9.0, "step": 0.5, "unit": "s", "sig": 2}
  ],
  "lets": [{"name": "v", "expr": "v0 + a*t", "unit": "m/s", "sig": 2}],
  "prompt": "初速度 ${v0|q}$ で進んでいた物体が、一定の加速度 ${a|q}$ で ${t|q}$ 間加速した。加速した後の速さを求めなさい。",
  "answer": "${v|q}$"
}
```

### 表示の部品(`parts`)

整形規則を当てて LaTeX を組み立てます。部品は上から順に作り、前の部品を差し込めます。

#### `sum`: 項の和

```json
{"name": "f", "kind": "sum", "terms": [{"coef": "a", "body": "x^{2}"}, {"coef": "b", "body": "x"}, {"coef": "c"}]}
```

項は `coef`(係数の式)と、その後ろに置く `body`(LaTeX)か `powers`(文字のべき)です。次の規則を当てます。

| 規則 | 例 |
| --- | --- |
| 係数が 0 の項は書かない | a = 2、b = 0、c = -5 → `2x^{2} - 5` |
| 係数の 1 は書かない(-1 は - だけ) | a = 1、b = -1 → `x^{2} - x` |
| `+-` は `-` にする | b = -3 → `- 3x` |
| 全部の項が 0 なら `0` | `0` |
| 分数・平方根の係数はそのまま前に置く | `\frac{3}{2}x`、`2\sqrt{3}y` |
| `powers` の指数が 0 ならその文字は書かず、1 なら指数を書かない | `{"coef": "a", "powers": [{"base": "x", "exp": "n"}]}` で n = 1 → `ax`、n = 0 → `a` |
| `"times": true` で、係数と本体の間に `\cdot` を置く(本体が数で始まる時) | `3 \cdot 2^{n-1}` |

`format` に `dec:1` や `sig:2` を書くと、係数をその桁で出します。

#### `product`: べきの積

`powers` のべきを順に並べます。指数が 0 のものは書かず、1 なら指数を書きません。`separator` で区切りを決めます(素因数分解なら ` \\times `、単項式なら省く)。全部の指数が 0 なら `otherwise`(省くと `1`)。

```json
{"name": "factored", "kind": "product", "separator": " \\times ", "powers": [{"base": "2", "exp": "e2"}, {"base": "3", "exp": "e3"}, {"base": "5", "exp": "e5"}]}
```

e2 = 3、e3 = 1、e5 = 0 なら `2^{3} \\times 3` になります。

#### `text`: 文字列の組み立て

```json
{"name": "ans", "kind": "text", "tex": "{inner|paren}e^{{a|coef}x}"}
```

#### `select`: 条件で選ぶ

上から順に、最初に成り立った `when` の `tex` を使います。どれも成り立たなければ `otherwise`。

```json
{"name": "sol", "kind": "select", "cases": [{"when": "rel.inside == 1", "tex": "{r1} < x < {r2}"}], "otherwise": "x < {r1},\\ {r2} < x"}
```

#### `list`: 値の並び

`items` の式を計算し、`unique` で同じ値を除き、`sort` で小さい順に並べて、`separator`(省くと `,\ `)でつなぎます。二次方程式の解が重解の時に `x = 2` と 1 つだけ出す、といった使い方をします。

```json
{"name": "roots", "kind": "list", "items": ["r1", "r2"], "sort": true, "unique": true}
```

#### `pm`: a ± b√c

`center ± scale × √radicand` を整理して書きます(`\frac{-1 \pm \sqrt{5}}{2}`、`1 \pm \sqrt{2}`、`\frac{-1 \pm \sqrt{3}i}{2}`)。根号が外れる時は 2 つの値を小さい順に並べ、根号の中が 0 なら 1 つの値にします。

```json
{"name": "roots", "kind": "pm", "center": "-b/(2*a)", "radicand": "b^2 - 4*a*c", "scale": "1/(2*a)"}
```

### 差し込みと書き方

`prompt`・`math`・`answer`・部品の LaTeX・点検の LaTeX には、`{名前}` で値を差し込みます。名前は変数・`lets`・`parts` のどれかです。宣言していない名前の `{…}` は、`^`・`_`・命令の直後にあれば LaTeX の波かっことしてそのまま残ります(`x^{n}`、`\frac{dy}{dx}`)。前に何も無い `{名前}` は、宣言し忘れた差し込みとして読み込みを断ります。

- `x^{n}`・`a_{n}`・`\frac{a}{b}`・`\sqrt{d}` のように、`^`・`_`・命令の直後にある差し込みは、値を入れた後も波かっこで囲みます(n = 12 の時に `x^{12}` になります)。
- `\mathrm{pH}`・`\text{…}`・`\vec{a}`・`\begin{cases}` などの直後の `{名前}` は差し込みにしません(同じ名前の変数があっても文字のまま)。

`|` の後ろに書き方を付けます。`{v|paren|dec:1}` のように重ねられます。

| 書き方 | 意味 | 例 |
| --- | --- | --- |
| (なし) | そのまま。整数、分数、平方根の整理した形 | `-3`、`-\frac{3}{4}`、`2\sqrt{3}`、`\frac{1+\sqrt{5}}{2}`、`2+3i` |
| `+` | 必ず符号を付ける | `+3`、`-3` |
| `coef` | 係数。1 は書かず、-1 は `-` だけ | `{a|coef}x` → `x`、`-x`、`2x` |
| `+coef` | 符号つきの係数 | `{b|+coef}y` → `+y`、`-y`、`+2y` |
| `paren` | 負の数と、項が 2 つ以上の数(1+√2、2+3i)をかっこで囲む。部品に付けると、項が 2 つ以上か負の符号で始まる時だけ囲む | `3 \times {b|paren}` → `3 \times (-2)`、`(-1-\sqrt{2})` |
| `+paren` | 符号を付けてかっこで囲む | `(+3)`、`(-5)` |
| `abs` | 絶対値 | `3` |
| `dec`、`dec:n` | 小数(割り切れる桁まで)、小数第 n 位まで | `0.25`、`0.67` |
| `sig:n`、`sci:n` | 有効数字 n 桁、必ず a × 10^n の形 | `2.0`、`3.4 \times 10^{2}` |
| `pi`、`overpi` | π の何倍か、π 分の何か | `\frac{2}{3}\pi`、`\frac{4}{\pi}` |
| `q` | 宣言した有効数字と単位を付ける | `2.0\,\mathrm{kg}` |
| `unit` | 単位だけ | `\mathrm{m/s^{2}}` |

名前の宣言に `sig` があれば有効数字で、`decimal`・`choice`・`constant` の変数は小数で、それ以外は分数で出します。

文字の変数(x、y など)と同じ名前を、型の変数に付けると混ざります。`\frac{x}{2}` の `x` を文字として出したい時は、型の変数に `x` という名前を付けないでください。

### 数値の点検(`checks`)

`left`・`right`・`tex`・`function`・`answer`・`integrand`・`term`・`solutions` は、差し込みを入れた後の LaTeX を数値にして確かめます。`equals`・`from`・`to`・`point`・`solution`・`conditions`・`at` の値は、型の式です。

| `kind` | 使うキー | 確かめること |
| --- | --- | --- |
| `identity` | `left`、`right`、`over`(省くと式に出てくる文字すべて)、`range` | 文字にいくつか値を入れて、2 つの式が等しい。展開・因数分解・式の計算に。文字が無ければ、2 つの式の値が等しい。 |
| `value` | `tex`、`equals`、`at` | 画面に出す式の値が、型の式 `equals` の値と等しい。 |
| `derivative` | `function`、`answer`、`variable`、`order`(1 か 2)、`point`、`over` | `function` を差分で微分した値が `answer` と等しい。`point` があれば、その点での微分係数が `answer` と等しい。 |
| `antiderivative` | `integrand`、`answer`、`variable` | `answer` を差分で微分した値が `integrand` と等しい(`C` は積分定数として読む)。 |
| `definite_integral` | `integrand`、`variable`、`from`、`to`、`answer` | 数値積分の値が `answer` と等しい。 |
| `root` | `left`、`right`(省くと 0)、`variable`、`solutions` | 解を代入すると等式が成り立つ。 |
| `system` | `equations`(`left`・`right` の組)、`values`(文字 → LaTeX) | 解を代入すると、どの式も成り立つ。 |
| `inequality` | `left`、`right`、`relation`、`variable`、`solution`、`where` | 変数に多くの値を入れて、不等式が成り立つ範囲と `solution`(変数を使った真偽の式)が一致する。`where`(変数を使った真偽の式)を書くと、その範囲だけで確かめる(定義域の中で最大値を超えない、など)。 |
| `assert` | `conditions` | 型の式の条件がすべて成り立つ。物理・化学で、別の関係式に代入して確かめる時に使う。 |
| `series` | `term`、`index`、`from`、`to`、`answer` | 項を足し上げた値が `answer` と等しい。 |
| `limit` | `function`、`variable`、`to`(式か `inf`・`-inf`)、`answer` | 近づけた時の値が `answer` に近い。 |
| `ode` | `function`(解)、`variable`、`left`、`right` | 解とその導関数(`y`、`y'`、`y''`)を代入すると微分方程式が成り立つ。任意定数には適当な値を入れる。 |

- `at` は、LaTeX の中の文字に入れる値です(`{"x": "x0"}`)。
- `range` は、文字に入れる値の範囲です(`[0.5, 3]`。対数や平方根のように、定義域が限られる時)。
- `tolerance` は、比べる時の相対誤差です(省くと 1e-6)。
- `relation` には差し込みも書けます(`{rel.tex}`)。`\le`・`\ge` も読みます。

LaTeX を数値にする時の読み方: `\frac`、`\sqrt`、`\sqrt[n]`、`^`、`_`(添字は名前の一部)、`\cdot`・`\times`・`\div`、掛け算の省略(`2x`、`3(x+1)`)、`\sin`・`\cos`・`\tan`・`\log`・`\ln`・`\exp` と `\sin^{2} x`、`\log_{2} 8`、絶対値 `|x|`、`\pi`、`e`、`i`、度 `30^{\circ}`、`\pm`(2 つの値)、コンマ区切り(複数の値)。`\log` は自然対数として読みます(常用対数は `\log_{10}`)。`\mathrm{…}` や `\text{…}`、行列の環境は数値にできないので、点検の LaTeX には入れません。数値にできる式は 200 語まで、かっこの入れ子は 24 段までです。

数値で確かめられない型は、`checks` を空にして、`no_numeric_check` に理由を書きます。
